# SQL BC01-DAT01 — bases de données

Bases de travail pour les **sessions live du cours SQL BC01-DAT01** (DataScientist.fr).

Un dossier par base, autonome : son propre `docker-compose.yml`, son propre `Makefile`, son propre README.
On se place dans le dossier et on lance `make up`.

| Base | Dossier | Contenu |
|---|---|---|
| **CareAccess** | [`careaccess/`](careaccess/) | Module M1 — 6 patients, 3 praticiens, 7 rendez-vous, 14 événements |

D'autres bases viendront s'ajouter au fil des modules.

```bash
cd careaccess
make up
```
